================================================================================
VZORY PRO akce.json
================================================================================

JSON nepodporuje komentáře, proto je tento soubor jako textová šablona.
Kopíruj jednotlivé bloky do akce.json a uprav hodnoty.

================================================================================
AKCE (koncert, festival)
================================================================================

{
    "typ": "akce",
    "nazev": "Název akce",
    "datum": "7. 2. 2026",
    "cas": "18:00",
    "misto": "Místo konání",
    "popis": "Popis akce - kdo vystupuje, co se bude dít...",
    "vstupne": "350 Kč",
    "letak": "images/letaky/nazev_letaku.jpg",
    "tlacitko_text": "Zobrazit leták",
    "tlacitko_link": "",
    "platnost_od": "",
    "platnost_do": "7.2.2026"
}

TLAČÍTKO:
- tlacitko_text = text na tlačítku (prázdné "" = tlačítko se nezobrazí)
- tlacitko_link = odkaz (prázdné "" = použije se cesta z letak)

Příklady:
- Bez tlačítka:      "tlacitko_text": "", "tlacitko_link": ""
- Leták:             "tlacitko_text": "Zobrazit leták", "tlacitko_link": ""
- Koupit lístky:     "tlacitko_text": "Koupit lístky", "tlacitko_link": "https://goout.cz/..."
- Web kapely:        "tlacitko_text": "Web JeDaRa", "tlacitko_link": "https://jedara.cz"

================================================================================
PŘÍSPĚVEK BEZ OBRÁZKU (kompaktní zobrazení s odkazem na FB)
================================================================================

{
    "typ": "prispevek",
    "datum": "1. 2. 2026",
    "nadpis": "Hraní v pivnici Svatý Mikuláš Vraclav",
    "text": "V sobotu jsme na pozvání kamaráda zajeli zahrát, zazpívat a popít. Sice s námi nejela Ája, ale i tak jsme snad ostudu neudělali.",
    "obrazek": "",
    "tlacitko_text": "Fotky na Facebooku",
    "tlacitko_link": "https://www.facebook.com/p/Pivnice-Vraclav/",
    "platnost_od": "",
    "platnost_do": "6.2.2026"
}

POLE PŘÍSPĚVKU:
- nadpis       = titulek příspěvku (volitelné)
- text         = popis, co se dělo
- obrazek      = cesta k obrázku (prázdné "" = kompaktní zobrazení bez obrázku)
- tlacitko_text = text na tlačítku (prázdné "" = tlačítko se nezobrazí)
- tlacitko_link = odkaz na FB album apod.

================================================================================
POZNÁMKY
================================================================================

- Položky se zobrazují v pořadí, jak jsou v JSON (nejnovější dej nahoru)
- Mezi položkami musí být ČÁRKA (kromě poslední!)
- Prázdné hodnoty: ""
- Formát data platnosti: D.M.YYYY (např. 1.1.2026 nebo 15.12.2026)
- Obrázky nahrát do images/letaky/ nebo images/novinky/
